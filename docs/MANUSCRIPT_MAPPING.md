The optional kernel checks reconstruct the documented 13-tap controls and new
path bank. Recorded measured paths can be regenerated only when the separate,
checksum-verified official trajectory archive is supplied.

V19 adds clearer separation of the 12 setting-level means from the 36 seed-family
endpoints, absolute recall summaries, conditional interval coverage, and worst-path
rates. These must be generated from existing seed-level and path-level exports,
not copied from rounded prose or substituted by new favorable runs.

The current repository preserves exported image-cluster CI endpoints but does
not recompute them without per-original prediction caches. Interval coverage is
conditional on fixed trained models and cutoffs, rather than a training-level CI.
